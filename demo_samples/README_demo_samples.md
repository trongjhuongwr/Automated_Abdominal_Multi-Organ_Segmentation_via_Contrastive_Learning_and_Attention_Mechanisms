# Demo samples

These .npz files were selected from Synapse/train_npz for Streamlit app demos.

- `showcase_multi`: many organs, good for the main demo.
- `organ_focus_*`: one representative slice for each organ class.
- `hard_small`: small foreground targets for stress testing.
- `background_only`: control slices with no organ label.

Open `selected_manifest.csv` for ranking details and `contact_sheet.png` for a quick visual overview.
